# Data sources and attribution

## KAIST varying-load rotating-machine dataset

Wonho Jung, Seong-Hu Kim, SungHyun Yun, Jaewoong Bae and Yong-Hwa Park,
“Vibration, Acoustic, Temperature, and Motor Current Dataset of Rotating
Machine Under Varying Load Conditions for Fault Diagnosis,” Mendeley Data,
Version 6 (2023), DOI: 10.17632/ztmf3m7h5x.6. Licence: CC BY 4.0.

This is the primary source for all five model classes, defect severity labels,
the grouped development evaluation, and the fault/condition models.

## Four-channel cross-speed dataset

Yakoop Qasim and Hassan Almubarak, “Four-Channel Vibration Dataset for
Cross-Speed Rotating-Machinery Fault Diagnosis at 600, 900, and 1200 RPM,”
Mendeley Data, Version 1 (2026), DOI: 10.17632/y8mv28hjwb.1. Licence: CC BY 4.0.

Only the 600-RPM records contribute to the active binary gate, at 1% auxiliary
weight. The 900-RPM and 1200-RPM records do not train the final artifact. They
are retained for cross-speed development checks. Raw dataset files are not
included in the handoff archive.
